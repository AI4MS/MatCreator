# Ticket 06 — Tracked Batch Job relaxation and AIDB archive

The tracked Batch Job tool uses the prepared relaxation input revision from ticket 05. A server-side stage copies the exact allowed scientific inputs and launcher, checks them against the authorized revision and submits that snapshot. The durable job stores the original request, expected runtime inputs, input digests, job token and AIDB binding. The generated launcher checks the staged files before and after the supported VASP command and emits the job token and SHA-256 of both finished outputs. This evidence relies on the selected provider and authorized VASP image executing the launcher as submitted.

Collection uses the tracked provider job ID to download into a private directory. It records the original workspace delivery directory and exposes workspace copies of the collected artifacts. The launcher receipt and POTCAR stay private. The receiver checks the receipt token and exact file digests, then validates the XML/OUTCAR pair using the active archive parser. It compares the actual initial structure, atom order, potential headers, INCAR and k points with the staged inputs. The parser checks terminal output, electronic and ionic convergence, and same-frame structure, energy, forces and any reported stress. VASP may omit the parallel-only NCORE tag from the XML. The launcher checksum still covers the submitted tag.

The AIDB receiver uses the active archive write and independent readback in the original session binding. Provenance records the provider and external run ID, the input and launcher digests, decoded XML/OUTCAR digests and the zero-based source frame. A tracked run's record identity combines provider/run fingerprint and source frame. Repeated collection uses the durable job and original artifacts and can retry a failed archive without another submission or transfer. An existing record without tracked provenance cannot attest the tracked run. The archive status and safe calculation artifact paths are available separately from verified computation status.
