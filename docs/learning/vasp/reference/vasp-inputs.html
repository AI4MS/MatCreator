一次 VASP 作业，需要哪些输入？

文件 / 设置职责本次要点
POSCAR晶格、元素、数量与坐标金刚石结构 Si
POTCAR按元素顺序组成的 PAW / 赝势数据只需一份 Si 数据块；两个 Si 原子也不是拼两份
INCAR计算方法、精度与优化参数PBE 泛函可通过 GGA=PE 明确选择；不改 POTCAR 的 LEXCH
KPOINTS / KSPACING倒空间采样采用 KSPACING 的输入可不提供 KPOINTS
run.sh初始化程序环境、启动 MPI / VASP属于运行方式，不能替代 POTCAR
PMG_VASP_PSP_DIR让 pymatgen 找到本机势库指库根目录；不是单次 POTCAR 文件，也不会让远端自动访问本机路径

记住这条路径

原始库：paw_pbe/Si/POTCAR.Z
  ↓ 解压、校验、适配当前 pymatgen 目录
工作库：pseudopotentials/POT_GGA_PAW_PBE/Si/POTCAR
  ↓ MPRelaxSet / MPStaticSet 生成输入
作业：INCAR + POSCAR + POTCAR + KPOINTS（按需）+ run.sh
  ↓ MatCreator tracked submit → bohr --input
远端：在作业目录运行镜像中的 VASP

三个字段

TITEL：势身份。ZVAL：每原子价电子数。ENMAX：势建议的截断能，INCAR 的 ENCUT 可覆盖它。

更换势后不能直接混用不同势的总能量基准。静态计算应沿用松弛步骤的势，保留 TITEL 与 SHA256。POTCAR 原始数据不应随意改写。

来源：POTCAR · GGA · Input · pymatgen；本次目录布局与上传行为以当前安装版本及 MatCreator adapter 源码为准。
